# سجل المختبر الطبي — React Native فعلي

هذه النسخة React Native حقيقية وليست WebView.

## الإضافات في هذا الإصدار
- استيراد نسخة احتياطية JSON من الهاتف.
- خيار استبدال البيانات الحالية.
- خيار دمج النسخة مع البيانات الحالية حسب `id`.
- نسخة احتياطية تشمل المرضى + الإعدادات + سجل التعديلات.
- طباعة Native عبر `expo-print`.
- إنشاء PDF ومشاركته.
- إعدادات A4 / Letter.
- اتجاه عمودي / أفقي.
- إظهار أو إخفاء القيم الطبيعية.
- قالب تقرير طبي منظم مع رأس التقرير وبيانات المريض والتوقيعات.
- تصدير Excel.

## تشغيل
```bash
npm install
npx expo start
```

## Android
```bash
npm run build:android
```

## Google Sign-In + Google Drive Native
- تسجيل دخول Google أصلي Native.
- رفع واستعادة نسخ المختبر من Google Drive باستخدام `drive.file`.
- استعادة أحدث نسخة وتحديث حالة التطبيق مباشرة.
- الاحتفاظ بآخر 5 نسخ.
- تفاصيل الإعداد في `GOOGLE_DRIVE_SETUP.md`.

> ملاحظة: Google Sign-In يحتاج APK/AAB مبنيًا Native؛ لا يعمل داخل Expo Go.
